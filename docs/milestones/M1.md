# M1: Lab + contracts

Gate: `terraform apply` builds the lab; `fns scout` writes the same snapshot digest
twice in a row; `scope.yaml` and contract JSON Schemas are published in `schemas/`.

M1 is split so that most of it needs no Azure at all. Do Phase A completely,
with `make check` green, before touching a tenant.

## Phase A: no Azure needed

### A1. Scaffold
- `uv init --package`, Python 3.12, package `fns` under `src/fns/`, console script `fns`.
- Layout:
  ```
  src/fns/
    cli.py              # Typer app: scout, contain, strike, harden, prove, molt, schema, scope, demo
    models/             # pydantic: scope.py, contract.py, snapshot.py, evidence.py
    scope/gate.py       # the only path to any SDK call
    adapters/azure/     # arm.py, graph.py (all calls via gate)
    journal/            # sqlite append-only run journal
    fixtures/           # record + replay
    report/             # (M2+)
    verify/             # (M3) must not import adapters/ executor code
  lab/                  # terraform
  contracts/examples/
  schemas/              # generated JSON Schemas (committed)
  fixtures/             # recorded API responses (placeholder GUIDs only)
  tests/
  docs/
  ```
- Makefile: `setup`, `check`, `schema`, `lab-up`, `lab-down`, `demo`.
- ruff, mypy --strict, pytest, hypothesis, pre-commit. GitHub Actions: `make check` on push/PR (no Azure).
- Rich theme using the brand palette in `docs/PLAN.md` section 11; ASCII banner on `fns --version`.
- Commands that are not built yet (`contain`, `strike`, `harden`, `prove`, `molt`) exit 2 with "not implemented in M1".

### A2. Models (Daniel reviews these personally before merge)
- `ScopeManifest`: tenant_id (GUID), subscription_ids, allowed_resource_groups,
  test_identities, allowed_operations per verb, budget (max_api_calls, max_minutes),
  expires_at. Validation: expired means invalid; empty lists mean nothing allowed.
- `Contract`: as in PLAN.md section 3. `must_not_reach` items are resource or
  directory targets with operations; `must_still_do` items carry `source: declared|recorded`.
- `Snapshot`: tenant_id, collected_at, collector_version, entities (typed: user,
  servicePrincipal, managedIdentity, application, group, directoryRole, roleDefinition,
  resource, scope), edges (typed: memberOf, owns, hasAppRole, hasDirectoryRole,
  hasRbacRole{scope, roleDefinitionId}, denyAssignment, contains), each with
  provenance {source_api, request_id?, observed_at}. Coverage block lists which
  collectors ran, partial failures, and what was not collected.
- `Finding` / `Evidence`: rung (modeled|evaluated|observed|logged), coverage state,
  verdict (pass|fail|inconclusive), reasons.
- Deterministic serialisation: sorted keys, entities sorted by id, edges by
  (type, src, dst); `digest()` = sha256 of canonical JSON excluding `collected_at`.
- `fns schema` writes `schemas/scope.schema.json`, `schemas/contract.schema.json`,
  `schemas/snapshot.schema.json`.

### A3. Scope gate
- `gate.check(verb, operation, target_resource_id | directory_target, tenant_id) -> Allowed | Denied(reason)`.
- `gate.call(...)` wraps every SDK call: checks, counts budget, logs to journal, raises on deny.
- Tests: table tests for allow/deny; hypothesis fuzz that generates random
  resource IDs, tenants and operations and asserts nothing outside the manifest is
  allowed; expired manifest denies everything; tenant mismatch denies everything.
- `fns scope check scope.yaml` validates and prints a summary.

### A4. Journal + fixtures
- SQLite journal: run_id, step_key (unique), status, started/ended, request
  summary, response digest. Idempotent step API.
- Recorder: wraps adapters, writes sanitized responses to `fixtures/<run>/`
  (tenant/object IDs replaced by stable placeholder GUIDs via a mapping that is NOT committed).
- Replayer: `fns demo scout` runs the collector against fixtures; every line of
  output and the snapshot carry `FIXTURE`.
- Hand-write one small fixture set now so Phase A is testable end to end.

Phase A done when: `make check` green in CI; `fns demo scout` produces a snapshot
with a stable digest; schemas committed.

## Phase B: Azure (needs the lab tenant)

### B1. Terraform lab (`lab/`)
- Providers: azurerm, azuread. Variables: tenant_id, subscription_id, location,
  name prefix. Tag everything `project=fang-and-scale`, `purpose=lab`.
- Resources per PLAN.md section 7 (without Log Analytics; that is M4).
- Outputs: object IDs, resource IDs; also renders `scope.lab.yaml` from a template.
- `make lab-up` / `make lab-down`. Document state is local and gitignored.

### B2. Live collectors (`fns scout`)
- ARM: role assignments + role definitions + deny assignments at subscription and RG scope.
- Graph: servicePrincipals, applications, owners of both, appRoleAssignments
  (Graph app permissions), directory role assignments, group memberships for in-scope principals.
- Read-only identity for scout: Reader on subscription + Graph application
  permissions limited to Directory.Read.All / Application.Read.All / RoleManagement.Read.Directory
  (document the exact set and why in README).
- Paging, throttling (429 Retry-After), partial failure recorded in coverage, not fatal.
- `--record` flag saves fixtures.

### B3. Gate check
- Run `fns scout` twice against the lab; digests must match.
- Contract example `contracts/examples/billing-agent.fns.yaml` validates against schema.
- Update README with: what M1 does, how to run the demo, the read-only permission set.
- Append decisions to `docs/DECISIONS.md`. Tag `m1`.
